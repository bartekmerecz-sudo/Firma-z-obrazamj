# Skille projektowe

Zainstalowane z dwóch zewnętrznych paczek (obie na licencji MIT).
Nie są naszym kodem — przy aktualizacji nadpisz cały katalog danego skilla.

## Z `content-skills` (Vyral) — treści na social media
- `viral-hooks` — pierwsze 1–3 sekundy filmu, archetypy hooków
- `viral-captions-and-ctas` — opisy, CTA, tekst na ekranie, strefy bezpieczne
- `viral-short-form`, `viral-short-form-ideas` — struktura scenariusza
- `viral-tiktok-content`, `viral-instagram-reels`, `viral-youtube-shorts` — specyfika platform

Używane przy `tools/gen_reels.py` — stamtąd pochodzą zasady:
hook rozstrzyga się do 3. sekundy, tekst poza strefami UI TikToka
(góra 150 px, dół 480 px), konkret zamiast ogólnika.

## Z `skills` (design/animacja)
- `apple-design`, `emil-design-eng` — zasady projektowania interfejsów
- `animation-vocabulary`, `improve-animations`, `review-animations`,
  `find-animation-opportunities` — animacje w UI
- `prototype`, `pick-ui-library` — prototypowanie
